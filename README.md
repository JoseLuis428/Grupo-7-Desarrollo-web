Star Coffee — Sprint 2

Maquetación estática en HTML + CSS de las páginas principales del sitio Star Coffee, previa a la 
implementación del backend con Node.js/Express y EJS (Sprint 3).

Qué se hizo en el Sprint 2

- Se diseñaron y maquetaron las páginas principales del sitio en HTML puro, con estilos en línea 
  (<style> dentro de cada archivo).
- index.html / home.html: encabezado con logo, buscador y menú de navegación; sección hero.
- producto.html: vista de detalle con imagen principal, miniaturas y pestañas de información.
- carrito.html: diseño en dos columnas con lista de productos y resumen del pago.
- registro.html: formulario de registro de usuario con tarjeta centrada.

Cómo verlo

Al ser HTML estático, basta con abrir cualquiera de los archivos .html directamente en el navegador 
(doble clic o clic derecho → Abrir con).

Notas

- Todavía no hay servidor ni datos dinámicos: cada página es un archivo independiente.
- Este maquetado sirvió de base visual para la migración a EJS realizada en el Sprint 3.
